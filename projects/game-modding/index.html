andrew kim / projects / game modding

i mod games for fun. rpg maker games ship their scripts, maps, and art inside a single encrypted archive, so to get at them i wrote ruby tools that unpack the two formats xp and vx ace use (rgssad v1 and v3).

the encryption

both formats xor the data in 4-byte blocks against a running key, and the key steps forward by k * 7 + 3 after each block. xp starts the key at a fixed 0xdeadcafe, while vx ace derives it from a seed stored in the archive header. that's the only real difference between the two. once you know the schedule, the same routine decrypts the file table and every file in it.

games that don't pack like that

plenty of games just keep their values in memory while they run. for those i use cheat engine. scan for a value, change it in game, scan again for the new value, and repeat until only the real address is left. then i can set it to whatever i want.
