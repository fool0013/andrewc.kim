andrew kim / projects / ti-32

a ti-84 that can ask an ai. it's my build of chromalock's ti-32. an esp32 inside the calculator connects to wifi and talks to a server, so a program on the calculator can send a question and show the answer on screen. i skipped their pcb and soldered the esp32 straight into the calculator's circuit.

i've never used it on a test.

my server

chromalock's repo comes with its own server. i wrote a smaller one. it takes the question from the calculator, asks an openai model with a prompt that keeps answers short enough for the screen, and sends back plain text, since that's what the calculator side expects.
