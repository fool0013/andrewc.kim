andrew kim / projects / calico 2026

calico 2026 was a team programming contest. i competed with edison yang and daniel li. they took problems 9 to 12, the hardest ones, and i took the other eight. we got a perfect score, 100 out of 100. results aren't out yet.

all eight of my solutions are below. the contest gave a template for each problem that handles the input, so these are the solve functions.

shock

earthquakes hit a grid of blocks one after another. each one reaches every block within its radius, and a block's seismometer ends up showing the most recent earthquake that reached it, at a level of p squared minus the squared distance, plus one.

going forward rewrites the same blocks over and over. going backward, from the last earthquake to the first, a block only ever needs to be set once, because the first earthquake to reach it going backward is the most recent one. to skip blocks that are already set, each row keeps a pointer to its next unset block, with path compression like a union-find, so every row of every earthquake jumps straight past the finished blocks.

forgor

a two-run problem. in the first run the program sees a tree and has to print n numbers. in the second run it gets those numbers back with one of them replaced by -1, and it has to rebuild the tree. the trick is to root the tree at vertex 1 and write down every other vertex's parent, which takes n - 1 numbers, then put the xor of all of them in the spare slot. the whole list xors to zero, so whichever number goes missing is just the xor of the rest.

galaxy

a grid of red, blue, and blank tiles. big ben can only step on tiles that match his current color, and blank tiles let him switch. one bfs over (tile, color) states labels every connected piece, so each query is just a lookup.

schedule

classes with one prerequisite each form a tree. each semester it takes up to k of the classes that are available, picking the ones with the longest chain of classes still behind them.

rain

drones fly east or north, and an east drone and a north drone on the same diagonal can run into each other. it groups drones by x + y, sorts the north ones, and binary searches how many each east drone meets.

smoke

two smoke charges that recharge one at a time. it walks through the requests in order, refilling charges as time passes, and fails as soon as a request comes in with nothing left.

verity

an interactive one. you guess a string and get told which spots are right. every round it fills the unknown spots with the next candidate letter and keeps whatever comes back correct.

prompt

the answer was appending the right phrase to an ai prompt, like "make_it_sound_human" when it asks you to write something.
