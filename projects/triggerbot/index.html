andrew kim / projects / triggerbot

a triggerbot for shooters. it watches a tiny box at the center of the screen and clicks the instant an enemy-colored pixel shows up in it. it never moves the mouse, so aiming is still on you. it just clicks faster than you would.

i wrote it for valorant and it worked. the color range further down is valorant's purple enemy outline. the account i ran it on got banned, which was the right call, and the only thing i point it at now is a target i wrote for it.

what it looks for

games that draw a bright outline around enemies make this easy. pick the outline color and watch for it. the box is only 6x6 pixels dead center, so the bot fires when the crosshair is already on target rather than hunting across the screen. the color range is in hsv, which holds up better than rgb when the outline shifts with lighting, and there's a fire delay so it taps instead of holding.

the loop

each pass grabs the box with mss, converts it to hsv, and builds a mask of the pixels inside the color range. a quick erode-then-dilate drops stray single pixels so a lone noisy dot can't make it fire. if anything survives, there's a target in the box, and it clicks.

something to shoot at

i wasn't going to drop into another live match to find out whether it still works, so i built the target instead. it opens a black fullscreen window, flashes a magenta square on the exact pixel the bot is watching, and times the gap between the square appearing and the click landing. it counts the squares the bot slept through and the clicks it fired at an empty screen.

the square is rgb 230, 50, 230. that converts to hsv 150, 200, 230, which sits in the middle of the range above, and all 36 pixels survive the erode and dilate, so the mask is guaranteed to light up. the target also reads your screen size first, because the bot hardcodes 1920 by 1080 and watches the wrong pixel on anything else.
